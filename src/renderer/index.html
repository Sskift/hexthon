02 / OVERLAY

你的外置浮层

独立透明窗口，始终鼠标穿透。游戏需使用无边框或窗口模式。

03 / RECOGNITION

本地中文识别

优先使用 Windows 中文识别；不可用时下载备用模型。仅识别可见文字，图片不上传。

识别区域占游戏窗口的百分比。默认识别中央卡片区域，可按分辨率调整。

模糊匹配会保留为待确认结果，不能保证每次识别成功。
