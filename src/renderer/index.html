01 / CONNECTION

连接国服客户端

自动发现 LeagueClient 本地连接。连接失败时，填写客户端 lockfile 文件或其所在文件夹。

仅在本地接口未返回队列时使用，对局结束后重置。
02 / GAME CONTEXT

只读取可用信息

通过本机接口跟随英雄、队友、备选池与当前装备。选人分析和出装参考集中在本面板中查看。

当前模式不显示游戏内外置浮层。商店开关状态和完整海克斯事件暂无可靠接口，未取得的数据保持未知。

游戏商店装备方案

将当前英雄路线放进游戏原生商店；开启自动更新后，随已读取的装备和强化调整，至少间隔 30 秒。

自动同步未开启
·
保留其他方案；检测到外部修改时停止覆盖。客户端读回成功不代表本局商店已即时刷新。
03 / PERFORMANCE

不采集游戏画面

截图、视频监控、OCR 与图标比对已关闭。后台只请求本机接口，不持续处理游戏图像。

海克斯资料仍可手动查阅与对照；已选信息不完整时，不会把未知状态当作已经识别。

尚无本轮识别耗时。

诊断不包含账号、凭据、画面或识别原文。客户端接口可用范围会随地区版本与补丁变化。
04 / DATA

资料与来源

OP.GG 公开的海克斯大乱斗页面，每 6 小时过期；网络不可用时保留最近缓存。

OP.GG 页面数据不代表国服统计。不同服务器、补丁和翻译可能有差异。

本机接口读取英雄、阶段、队友和装备；魄罗佳肴不计入装备构筑。

Hexthon 是独立的开发原型，未获 Riot、腾讯或 OP.GG 背书。
