# Hexthon 0.4.0 发布与验证记录

记录日期：2026-11-03。本版补齐原生装备方案的生产接入，并扩展推荐约束、补丁保护、诊断和性能测量工具。**腾讯客户端装备方案导入、读回与撤回已验证；三卡／商店／HUD 的国服多局准确率、局内装备页热刷新与游戏 FPS 尚未验收。**

## 本版行为

`npm start` 继续使用无画面采集的接口模式；`npm run start:assist` 使用指定前台游戏窗口的小区域识别与按场景自绘浮层。已有暂停、退出保存和按局恢复行为保留。原生装备方案开关 `nativeItemSets` 默认 `false`，与视觉识别暂停分别控制。

| 功能 | 本版变化与边界 |
| --- | --- |
| 原生装备方案 | 自绘设置页可显式导入当前查阅英雄、检测接口、撤回 Hexthon 方案。可选自动同步仅在实际 Mayhem 选人／对局、英雄和资料匹配时运行，间隔至少 30 秒。导入预览英雄无需伪造对局状态。 |
| 写入与撤回保护 | 固定本机回环地址及窄端点白名单，核验当前数字身份与稳定 PUUID；凭据只在内存。写前保存目标页回滚记录，再读集合并重验身份／上下文，写后读回。撤回只恢复仍匹配记录的 Hexthon 目标页，保留其他页面和新修改；异常与冲突停止覆盖。 |
| 腾讯读回规范化 | 实测客户端会省略 `priority:false` 并补充 `preferredItemSlots:[]`。仅这两种默认表示等价；非空槽位、`priority:true`、标题、装备顺序及其他字段变化仍受冲突保护。 |
| 推荐约束 | 补充属性转换后的原属性收益保护、终极技能禁用与依赖冲突，保留部分任务／装备前置、奖励和互斥规则。推断证据保留条件提示；不估算未读取的转换数值、结算顺序或完整组合收益。 |
| 兼容性 | 已知游戏与资料补丁不匹配时显示警告并暂停装备方案同步；静态装备属性与游戏补丁不匹配时停用对应属性推理。缺少版本信息保持未知。 |
| 运行负担 | 推荐上下文相同时复用结果；扫描耗时过高或连续失败时退避，避免持续按最短间隔重试。这些策略已接入，不等同游戏帧率改善结论。 |
| 诊断导出 | 面板生成状态、覆盖计数、兼容性和有界耗时摘要；不导出画面、OCR 文本、账号标识、凭据或进程命令行。 |
| 分发检查 | 已配置 Windows CI、包内必需文件／开发文件排除检查，以及逐文件 SHA-256 清单。本地 Windows 包构建及完整性检查已通过，约 421 MiB；CI 尚待远端执行，未配置代码签名或自动更新。 |

原生方案使用整个集合的 LCU PUT。二次读取、身份校验和读回可以发现已观察到的冲突，但没有已验证的 CAS／事务接口，不能保证读写间隙绝对不存在第三方竞争。没有删除游戏自带推荐文件，也不自动购买装备。

## 中文标题的明确缺口

目录测试使用离屏绘制的微软雅黑标题和平面背景，再运行真实 Windows OCR。每种分辨率生成 88 组三卡，并非 88 场真实对局。

| 分辨率 | 完整三卡 | 正确标题 |
| --- | --- | --- |
| 1920×1080 | 66/88 | 239/264 |
| 1280×720 | 39/88 | 192/264 |
| 2560×1440 | 79/88 | 255/264 |
| 合计 | 184/264 | 686/792 |

本批未出现误认，但未读全的三卡仍不能显示推荐。720p 的 39/88 完整率是明显缺口；长标题、断行与 OCR 漏字仍需改进。目录中“罪恶快感！”与“罪恶快感”的规范化名称冲突，以及纯标点“？？？”无法唯一匹配时，保持拒识。不能将保守拒识称为全面解决识别，也不能把合成文字的结果外推为国服实局准确率。

复现入口为 `npm.cmd run test:catalog`，详细报告在 `.qa/title-catalog/report.json`。

## 后续验收与外部依赖

- **真实多局与性能**：仍需三卡、商店、HUD、选人浮层和关闭时机的多局验证，以及相同场景下暂停／启用的多轮帧时间对照。正式测量方式和边界见 [FRAME_TIME_VALIDATION](FRAME_TIME_VALIDATION.md)。当前没有“不卡顿”或“零开销”的证据。
- **完整状态与统计来源**：完整已选始终 `complete:false`；敌方海克斯、可靠刷新次数及可核查的胜率／样本量仍无完整来源。职业规则阵容评分和推荐指数不等于胜率或最优五人阵容。
- **原生商店热刷新**：客户端读回成功不证明当前游戏立即重新加载页面；仍需局内确认显示时机与位置。
- **Overwolf**：独立运行时可启动，GEP 仍需要开发凭据；腾讯国服真实候选／选择事件尚未验证，不是当前主应用依赖。
- **发行与维护**：代码签名、自动更新／自动回退和远端 CI 成绩未完成。SHA-256 清单用于文件完整性核对，不替代发行者签名。

竞争产品及来源的既有核查见 [PRODUCT_GAPS](PRODUCT_GAPS.md)；旧 [无截图调研](NO_CAPTURE_RESEARCH.md) 和 [0.3.1 预检](PREFLIGHT_0.3.1.md) 保留为历史记录，当前接入状态以本版文档为准。
